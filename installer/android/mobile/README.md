# installer/android/mobile

スマホ用の署名つき APK `maid-cafe-se_<version>_android.apk` は、容量を増やさないため、Git の履歴には入れていません。

- **最新版をダウンロード**: [Releases](https://github.com/aon-co-jp/maid-cafe-se/releases/latest)(`maid-cafe-se_<version>_android.apk`)
- フォルダとして見る: [`installer` ブランチ](https://github.com/aon-co-jp/maid-cafe-se/tree/installer/android/mobile)(最新版だけが入っていて、リリースのたびに自動で入れ替わります)

手元でビルドした APK は、このフォルダに出力されます(`.gitignore`で、コミットの対象外)。
